ffmpeg : https://ffmpeg.org/
deno : https://deno.com/



TIP - to update yt-dlp or ffmpeg or deno,
then delete their exe file within "scriptData" and launch "yt-dlp-auto-expanded.bat",
it will auto-install the lastest version if they are missing


TIP - If you want to get faster downloads AND not get the "Too many requests" error, then do this..

	1. get the Get cookies.txt LOCALLY extension
	(https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)

	2. open with the extension youtube (mostly the home page)

	3. then click on the extension's icon on the topbar of your browser

	4. press "Export As" in the window that popped up

	5. then save it as "cookies.txt" in the same folder as "yt-dlp-auto-expanded.bat"

	6. then just use ytdlp-auto-expanded!


	NOTE: for the "faster downloads tip"...


	NEVER give this "cookies.txt" file to anyone,

	and since this is written in batch, you can check the code
	to see that it doesn't try to steal your cookies.
